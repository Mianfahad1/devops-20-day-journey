This repository documents my progress, labs, projects, configurations, troubleshooting, and practical implementations throughout a structured 20-day DevOps journey.

## 🎯 Goals

- Build practical DevOps engineering skills
- Strengthen Linux and networking fundamentals
- Work with cloud infrastructure and AWS (VPC, EC2, EKS, S3, IAM, EBS)
- Master Git and GitHub workflows
- Learn containerization with Docker & Docker Compose
- Understand CI/CD pipelines with Jenkins
- Practice infrastructure as code with Terraform
- Configure servers at scale with Ansible
- Deploy and orchestrate applications with Kubernetes, Helm & ArgoCD
- Implement monitoring, logging, and security practices
- Prepare for DevOps internships and entry-level roles

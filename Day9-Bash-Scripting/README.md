## 🎯 Objectives
- Understand the fundamentals of shell and shell scripting.
- Write and execute basic shell scripts (Variables, Comments, Inputs & Outputs).
- Automate user management and backup operations.
- Implement loops, conditional statements, and functions.
- Add error handling to ensure scripts are safe to re-run (idempotent).

## 🚀 Scripts Created
- **hello_world.sh**: Basic script to print output.
- **users_creation.sh**: Interactive script to onboard new developers.
- **create_user.sh**: Script using positional arguments to add users with default passwords.
- **backup_script.sh**: Automates daily backups of important files.
- **system_report.sh**: Reads user input and outputs a full system report (disk, uptime, user).
- **disk_alert.sh**: Checks disk usage and triggers alerts if above 80%.
- **check_website.sh**: Pings a website to ensure connectivity.
- **check_service.sh**: Checks if critical services (SSH, Apache2) are running.
- **setup_repo.sh**: Error-handling functions to safely create folders and clone GitHub repos.
- **master_automation.sh**: A master script combining all monitoring and backup tasks into one command.

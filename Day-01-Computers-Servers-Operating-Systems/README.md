# 🚀 Day 1 — Computers, Servers & Operating Systems

## 📌 Overview

Day 1 focused on understanding Linux servers and performing practical system administration tasks on an AWS EC2 instance.

For this lab, I used an Ubuntu 24.04.4 LTS AWS EC2 instance running my Wazuh Manager environment.

The goal was to understand how a DevOps engineer inspects, monitors, and troubleshoots a Linux server.

---

## 🎯 Objectives

- Understand the role of a Linux server
- Identify operating system and kernel information
- Inspect CPU, RAM, storage, and system load
- Monitor running processes
- Understand Linux services and systemd
- Check service health and failures
- Understand Linux file permissions
- Practice chmod
- Understand SSH connectivity
- Inspect services running on a real AWS server
